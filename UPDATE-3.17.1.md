# Conquest SMP 3.17.1

Leaderboard text now uses normal depth testing, so it does not draw through intervening blocks or player models. Player-head items rotate 180 degrees around their own local vertical axis so their faces point toward the viewer. Camera-facing behavior, positions, spacing, scale, colors, backgrounds, statistics and all four saved placements are unchanged. Existing leaderboards.yml is retained.

Built against Paper 1.21.11. Existing automated regression suite and packaged SQLite check run with the build. Actual client occlusion and head appearance need in-game visual confirmation.
