# Conquest SMP 3.16.0

Adds /rtp exclusively in world_terralith. Commands from other dimensions/worlds are refused. Searches up to 16 asynchronously loaded chunks, allows four concurrent requests, and times out after 20 seconds. Selects dry solid landing spots within the current border with a one-block margin, rechecks border and combat before teleporting, and respects teleport cancellation. Combat blocks use, except the existing four senior administrative roles. Searches clean up on logout and shutdown.

Verification: 271 automated tests passed, including RTP offset/shrinking borders, hazardous landings, wrong-world rejection and combat rejection. Packaged SQLite smoke test passed. Actual player RTP, chunk-generation performance and Minecraft client visuals have not been tested in game.
