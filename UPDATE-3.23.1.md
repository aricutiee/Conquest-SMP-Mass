# Conquest SMP 3.23.1

The IP line now uses exactly the same five-pixel small-caps glyphs, size, baseline and bold weight as the Conquest SMP title. The previous enlarged, unbold IP rendering has been removed.

Every custom-font scoreboard letter and number now has a vertical gradient within the glyph: light purple (#C69AFF) at its top and bottom, with dark purple (#60308F) at its middle. This includes the title, section headings, labels, values and IP address. Icons and separators remain purple.

The resource pack is rebuilt and embedded in the plugin. Clients that decline the pack retain the readable Unicode small-caps fallback; a vertical per-pixel gradient requires the pack.
