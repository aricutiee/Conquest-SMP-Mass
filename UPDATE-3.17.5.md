# Conquest SMP 3.17.5

Warlord death and preview animations play the selected 13-second opening of The Dread by Kevin MacLeod, with short fades. The Ogg Vorbis clip is bundled in the existing resource pack, streamed at normal pitch, and stopped with animation cleanup. Existing pack hosting updates its SHA-1 so Java clients download the revised pack on join. Bedrock retains the vanilla music-disc fallback because this is a Java resource pack.
